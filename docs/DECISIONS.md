# Decisions

Dated entries for anything that deviates from or refines docs/PLAN.md.

## 31 Oct 2026 — Build location (temporary)

`aidigitallabs/tumble-trail` did not exist when the build started, so the game is being
built under `cc-ops/games/tumble-trail` on branch `ccr-c90fa07a-a1hn6q`. It is written as a
standalone project (own package.json, own `.github/workflows/`) so it can be moved with
`git subtree split --prefix=games/tumble-trail` once the repo exists. Until then the
workflows in `.github/workflows/` do not run (they are not at the cc-ops root) and the Pages
URL does not exist. Agents run the same checks locally instead.

## 31 Oct 2026 — Playwright

The build environment has Playwright 1.63.0 and Chromium 1243 preinstalled under
`/opt/pw-browsers`. `@playwright/test` is pinned to 1.63.0 and `npx playwright install` is
NOT run locally (CI runs it). `executablePath` is taken from `PLAYWRIGHT_CHROMIUM_PATH` when
set, otherwise the bundled browser is used.

## 31 Oct 2026 — Phase 0 decisions

- **Extra dev dependencies.** `@types/three` (three ships no type declarations; strict TS needs
  them), `@eslint/js` and `globals` (the standard building blocks of the eslint flat config that
  typescript-eslint documents). None are runtime dependencies. No other additions beyond PLAN
  section 3. `workbox-build` and `workbox-window` come in as peers of `vite-plugin-pwa` and are not
  listed separately.
- **TypeScript 6.0.3, not 7.x.** `npm view typescript` reports 7.0.2, but the latest
  `typescript-eslint` (8.72.1) declares `typescript: >=4.8.4 <6.1.0`, so npm resolved 6.0.3. Not
  downgraded by hand; bump both once typescript-eslint supports 7.
- **Prettier.** `.prettierrc.json` sets `singleQuote` and `printWidth: 100` (otherwise defaults).
  Small deviation from "defaults" to keep lines readable. `docs/PLAN.md` is excluded from prettier
  so the spec text is never reformatted.
- **Lint script** is `eslint . && prettier --check .`, so one `npm run lint` covers both.
- **`npm run build`** is `tsc --noEmit && vite build`, so a type error fails the build too.
- **Service worker.** `vite-plugin-pwa` with `registerType: 'prompt'`, `injectRegister: false`
  and a manual `registerSW()` call in `main.ts`, skipped in dev. `workbox.maximumFileSizeToCacheInBytes`
  is raised to 8 MiB because the Rapier-compat bundle (WASM embedded as base64) is about 4.8 MB
  raw; without this the main chunk would silently not be precached. `chunkSizeWarningLimit` is
  raised to match so the build log is not noisy. Applying updates only on the title screen arrives
  in Phase 4; Phase 0 just registers.
- **CI wiring.** `ci.yml` runs on pushes to every branch except `main`, on pull requests, and as a
  reusable workflow. `pages.yml` (push to `main`) calls it first and only deploys if it passes, so
  `main` pushes run CI exactly once.
- **e2e server.** Playwright's `webServer` runs `npm run build && vite preview` with
  `VITE_BASE=/`, so e2e always tests a fresh production build, locally and in CI.
- **`__tt` in Phase 0.** Only `state`, `stats()`, `ball()` (position and velocity, `t` and
  `lateral` are 0) and `app.rendererString` exist. The smoke test uses `ball()` to prove Rapier is
  stepping (the ball drops from 4 m and rests on the plane) and `rendererString` to prove WebGL is
  real. The rest of the contract arrives in Phase 1b.
- **Icons.** Generated by `scripts/make-icons.mjs` with `sharp` from an inline SVG (red and white
  quartered ball, dark rim, pastel sky and meadow). PNGs are committed in `public/icons/`:
  192, 512, 512 maskable and a 180 px full-bleed apple-touch-icon.
